# デプロイ手順（APIサーバー・Vercel）

## 事前準備

- `server/api/index.ts` を用意済み（VercelのNode.js Serverless FunctionsとしてExpressアプリを動かすための入り口）
- `server/vercel.json` で、すべてのパスをこの関数にルーティングする設定を用意済み

## 手順

1. [Vercel](https://vercel.com/)にログインし、「Add New... → Project」からGitHubリポジトリ（`hosawa-td/tadaimap`）をインポートする
2. プロジェクトの設定画面で、**Root Directory を `server` に設定する**（アプリ本体`app/`はデプロイ対象に含めないため）
3. Framework Presetは「Other」のままでよい
4. 「Environment Variables」に、以下の3つを設定する（`server/.env.example`と同じ内容）
   - `GOOGLE_SHEET_ID`
   - `GOOGLE_SERVICE_ACCOUNT_EMAIL`
   - `GOOGLE_PRIVATE_KEY`（サービスアカウントの秘密鍵。改行は`\n`のまま1行で貼り付ける）
5. 「Deploy」を押す
6. デプロイ完了後に発行されるURL（例：`https://tadaimap-xxxx.vercel.app`）を、スマホアプリ側の`app/.env`の`EXPO_PUBLIC_API_BASE_URL`に設定する

## 注意点

- 環境変数を後から変更した場合、それだけでは反映されない。設定変更後は「Deployments」タブから再デプロイする（空コミットのpushでも再デプロイのトリガーになる）
- デプロイ後のURLは、確認でき次第この設計書に追記する

## デプロイ結果

- デプロイURL：https://tadaimap.vercel.app
- 実際にGoogleスプレッドシートへの読み書きも含めて動作確認済み（2026-09-18）

## トラブルシューティング（発生した事例）

- **`FUNCTION_INVOCATION_FAILED`**：VercelのExpress自動検出が`src/app.ts`をエントリーポイントとして扱うため、同ファイルにdefault exportが必要（対応済み）。
- **`DECODER routines::unsupported`エラー**：`GOOGLE_PRIVATE_KEY`の環境変数の前後に引用符(`"`)が入っていると発生する。値は引用符を含めずに貼り付けること（プログラム側でも自動的に引用符を除去するよう対応済み）。
