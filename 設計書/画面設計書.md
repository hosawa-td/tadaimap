# タダイマップ 画面設計書

Google Stitchで作成した本番デザイン（`stitch_export/`、画面イメージは`screens/`に整理）をもとにした画面一覧・画面遷移・要素定義。

## 1. デザイントークン（DESIGN.md より抜粋）

- コンセプト名：Warm Hearth Presence（温かい家の灯り）
- メインカラー（Primary）：`#182430`（ディープネイビー）
- アクセントカラー（Secondary）：`#D9920A`（ウォームアンバー）
- 在宅ステータス色（Tertiary）：`#4A7C59`（セージグリーン）
- 施設内ステータス色：`#B9770E`（アンバー系、`colors.nearby`）
- 不在ステータス色：`#7D8A99`（ソフトスレート）
- ベース背景：`#FDF8F0`（ウォームクリーム）
- カード背景：`#FFFFFF`
- 見出しフォント：Plus Jakarta Sans／本文フォント：Noto Sans（日本語フォールバック：Noto Sans JP）
- 形状：角丸を基調（カード24〜32px、ボタン・チップは完全な丸みのpill形状）
- 影：ごく淡いものに限定し、色面の階調で立体感を出す

詳細トークン（色・タイポグラフィのフルセット）は `stitch_export/stitch_/warm_hearth_presence/DESIGN.md` を参照。

## 2. 画面一覧・画面遷移図

```
[スタート画面]
   ├─(家族グループを作る)──▶ [グループを作る画面] ──(次へ)──▶ [自宅の登録画面] ──(保存)──▶ [ホーム画面]
   └─(招待コードを持っている)▶ [招待コードで参加する画面] ──(参加する)──▶ [自宅の登録画面] ──(保存)──▶ [ホーム画面]

[ホーム画面] ⇄(タブ)⇄ [設定画面]
[設定画面] ──(自宅の位置・判定範囲の変更)──▶ [自宅の登録画面] ──(保存)──▶ [設定画面へ戻る]
[設定画面] ──(グループからの退出)──▶ 確認ダイアログ ──(退出する)──▶ [スタート画面]
```

画面遷移・操作時の動きは、dev-kickoffで作成したプロトタイプの内容から変更しない。

## 3. 画面ごとの定義

### 3.1 スタート画面（`screens/01_start.png`）
- アプリロゴ・アプリ名「タダイマップ」・キャッチコピー
- 位置情報の使われ方についての説明（安心設計であることを明記：詳細ピン非公開／行動履歴の保存なし／端末内暗号化）
- ボタン：「家族グループを作る」（プライマリ）／「招待コードを持っている」（セカンダリ）

### 3.2 グループを作る画面（`screens/02_create_group.png`）
- ステップ表示（STEP 1/2）
- 発行された招待コード（6桁数字）とコピー操作、有効期限表示（7日間）
- 自分の名前の入力欄（候補チップ：お父さん／お母さん／じいじ／ばあば）
- 「次へ進む（自宅の設定へ）」ボタン（名前未入力時は非活性）

### 3.3 招待コードで参加する画面（`screens/03_join_group.png`）
- 招待コード入力欄（6桁、1桁ずつのマス目形式）
- 自分の名前の入力欄（候補チップ）
- 「グループに参加する」ボタン（両方未入力時は非活性）
- 「コードが見つかりませんか？」の案内文

### 3.4 自宅の登録画面（`screens/04_register_home.png`）
- 地図イメージ上に、自宅位置のピンと、2つの判定範囲の円（在宅＝内側・アクセントカラー、施設内＝外側・`colors.nearby`）を表示
- 「現在地を設定」ボタン
- 在宅判定の半径スライダー（50m〜300m、初期値100mを「おすすめ」として表示）
- 施設内判定の半径スライダー（在宅判定の半径〜2000m、初期値300m。在宅の半径を上げると自動的に追従して広がる）
- 半径選択時の補足説明（広すぎ／狭すぎの注意点）
- 「この位置で保存する」ボタン

### 3.5 ホーム画面（`screens/05_home.png`）
- ヘッダー：グループ名（「わが家」）・招待コード表示に加え、右上に**「更新」ボタン**（家族全員の最新状態を手動で再取得。通信中はスピナー表示）
- 在宅人数バッジ（例：「現在2/3人 在宅中」。「施設内」は在宅人数に含めない）
- **3択の状態切替スイッチ**（「在宅」／グループ共通の呼び方（初期値「施設内」）／「外出中」）。押した状態がアクセントカラーでハイライトされる
- 自分の状態が「在宅」のとき、その下に**在宅中の詳細な状態の入力欄**を表示：左に「×」（即クリア、未入力時は非活性）、中央にテキスト入力（プレースホルダー「トイレ中・入浴中 など（任意）」）。入力欄からの離脱・キーボードの確定操作で自動保存される
- 管理者には、一覧の上に「管理者として、家族の名前を長押しすると代わりに状態を変更できます」という案内文を表示
- メンバー一覧：アバター、名前（または匿名表示）、本人には「あなた」ラベル、管理者には「管理者」ラベル、最終更新時刻、状態バッジ（在宅＝セージグリーン／施設内＝アンバー系／外出中＝ソフトスレート）。在宅かつ詳細な状態が設定されている行には、それを小さくアクセントカラーで追加表示
- 管理者が他のメンバーの名前を長押しすると、対象の状態を選ぶボトムシート（在宅にする／〈呼び方〉にする／外出中にする／**このメンバーを削除する**（赤字）／キャンセル）が開く。背景の暗い部分をタップしても、何も変更せずに閉じられる
- 下部タブ：ホーム／設定

### 3.6 設定画面（`screens/06_settings.png`）
- 自分のプロフィール（アバター・名前・現在のステータス・所属グループ名）
- ユーザー情報・表示設定：名前の変更、名前を家族に表示するかどうかのスイッチ
- **近くにいるときの呼び方**：管理者には編集可能なテキスト入力欄、管理者以外には読み取り専用のテキストとして、グループ共通の値を表示する
- 位置と通知：自宅の位置・判定範囲の変更（在宅・施設内の両方の半径を表示）、帰宅/施設内/外出のプッシュ通知スイッチ
- 家族グループ：招待コード表示・コピー・有効期限、メンバー一覧
- **参加している他のグループ**：2件以上参加している場合のみ表示。グループごとに「（そのグループでの自分の名前）として参加中」の行と、いま表示中でなければ招待コード（見分けやすくするため）と「切り替え」ボタンを表示。この一覧は画面を開くたびにDBから取り直す（F18を参照）
- **別の招待コードで参加する**ボタン（招待コードで参加する画面へ遷移。参加中の他グループはそのまま維持される）
- グループからの退出（危険操作、赤字表示）
- **グループを削除する**（管理者のみ表示、危険操作・赤背景。取り消せない旨と、参加者全員が削除される旨を確認ダイアログで明示）
- アプリバージョン表示、利用規約・プライバシーポリシーへのリンク

### 3.7 Web版画面（`server/public/index.html`、1ファイル構成）

ネイティブアプリを入れられない端末（主にiPhone）向けの簡易画面。デザイントークンはネイティブアプリと共通（Warm Hearth Presence）。

- **参加画面**：招待コード（6桁）・名前の入力、「参加する」ボタン（グループの新規作成は非対応、ネイティブアプリのみ）
- **わが家画面**：
  - ヘッダー：バッジ「🏠 わが家」＋右上「更新」ボタン、在宅人数、招待コード
  - 3択の状態切替ボタン（在宅／グループ共通の呼び方／外出中）
  - 自分が在宅のときのみ、在宅中の詳細な状態の入力行（左「×」ボタン＋テキスト入力）を表示
  - メンバー一覧カード：アバター・名前・「あなた」／「管理者」タグ・最終更新時刻・在宅中の詳細な状態（小さくアクセントカラーで表示）・状態バッジ。管理者が閲覧している場合、自分以外のカードはタップ可能になり、状態変更メニュー（モーダル）が開く
  - 設定：名前、名前の表示切替、呼び方（管理者のみ編集可・それ以外は読み取り専用）、通知（Web Push）のON/OFFスイッチ（未対応環境やiPhoneでのホーム画面未追加時は案内文を表示）
  - **家族グループ**：2件以上参加している場合のみ、参加中グループの一覧（招待コード・切り替えボタン付き）を表示。「別の招待コードで参加する」ボタン（押すと参加画面に戻るが、既存の参加はそのまま維持され「キャンセルして戻る」ボタンが表示される）。この一覧は画面を開くたびにDBから取り直す（F18を参照）
  - グループからの退出、**グループを削除する**（管理者のみ表示、危険操作）
  - 画面下部の注記：通知が有効な場合は通知受信時に自動更新される旨、それ以外は手動更新が必要な旨を明記
- **管理者用ステータス変更モーダル**：対象メンバー名＋「在宅にする／〈呼び方〉にする／外出中にする／**このメンバーを削除する**（赤字）／キャンセル」の5ボタン。背景の暗い部分をタップしても閉じられる
- **Service Worker（`sw.js`）**：Web Pushの受信・通知表示、通知タップ時のウィンドウ復帰、開いている画面への即時更新の合図送信を担当
- **ホーム画面追加対応**：`manifest.json`・`apple-touch-icon`・関連メタタグにより、iOSでも見た目の整った「ホーム画面に追加」が行える
- **保存の耐障害性**：参加情報（端末ID・参加中グループ一覧）はlocalStorageに加えてcookieにも複製し、iPhoneのSafari等でlocalStorageが失われた場合に自動復元する（F14）

## 4. build-kickoff段階で確定した追加仕様（要件定義からの変更点）

デザイン作成の過程で、以下2点を追加仕様として確定した（ユーザー確認済み）。

1. **招待コードに有効期限を設ける**：発行から7日間。期限切れの場合は設定画面から再発行できる（F10）。
2. **手動の「ただいま」通知機能を追加**：自動判定を待たずに、自分から家族へ在宅を知らせるボタンをホーム画面に設置する（F6）。

なお、Stitchのデザイン案に含まれていた以下の要素は、要件に含まれないため**採用しない**（装飾的な提案であり、具体的な仕様が定義されていないため）。

- ホーム画面の「おかえりなさいの準備（夕食や施錠の確認）」という提案カード

## 5. 実装完了後に追加した仕様（ユーザー確認済み）

build-kickoffでの本実装が完了した後、実運用でのフィードバックをもとに以下を追加した。詳細は`機能設計書.md`のF12〜F17を参照。

1. **3段階ステータス化**：「在宅」「外出中」の2択に、「施設内」（マンション等の同じ建物内の別の場所にいる状態）を追加。自動判定は2重のジオフェンスで行い、手動でも3択スイッチで切り替えられる。
2. **管理者ロール**：グループを作成した人が自動的に管理者になり、他のメンバーの状態を代わりに変更できる（長押し／タップでメニュー表示）。
3. **呼び方のグループ共通化**：「施設内」の表示名は、個人ごとではなくグループで1つの値とし、管理者のみが変更できる。
4. **Web版（ブラウザ簡易画面）**：ネイティブアプリを入れられない端末（主にiPhone）向けに、招待コード参加・一覧・手動切替・設定を行える簡易画面を追加。Web Push（VAPID）によるプッシュ通知にも対応。
5. **在宅中の詳細な状態**：「トイレ中」等、任意の一言メモを在宅中に添えられる機能を追加（本人のみ設定可、状態が変わると自動的にリセット）。
6. **一覧の手動更新ボタン**：ホーム画面右上に「更新」ボタンを追加し、いつでも最新の状態を再取得できるようにした。
7. **複数グループ参加・管理者によるメンバー削除／グループ削除**：1台の端末が複数の家族グループに参加し、設定画面から切り替えられるようにした。あわせて、管理者が他のメンバーを削除する機能、グループそのものを削除する機能を追加。管理者用ダイアログは背景タップで閉じられるよう変更し、Web版はlocalStorageが失われた場合に備えてcookieへも参加情報を複製するようにした。詳細は`機能設計書.md`のF18〜F20を参照。
8. **参加中グループ一覧のDB同期**：端末内に保存している「参加中グループ一覧」は、あくまでキャッシュとして扱い、アプリ起動時・設定画面を開いたとき（Web版は画面表示のたび）に`GET /memberships`でDBの実際の内容と同期するようにした。これにより、端末の保存領域が失われた場合でも参加状況を復元できる。あわせて、一覧の各行に招待コードを表示し、同じ名前で複数グループに参加している場合でも見分けやすくした。
