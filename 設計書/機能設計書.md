# タダイマップ 機能設計書

各機能について、入力・出力・処理内容（業務ロジック）をまとめる。

## F1. 家族グループの作成

| 項目 | 内容 |
|---|---|
| 概要 | 新しい家族グループを作成し、招待コードを発行する |
| 入力 | 自分の名前（表示名） |
| 出力 | グループID、招待コード（6桁数字）、自分のメンバーID |
| 処理内容 | 1. 端末固有のデバイスIDを生成（初回起動時に端末内へ保存）。 2. グループIDを新規発行。 3. 招待コード（6桁の数字、重複しないもの）を発行し、**発行から7日間**を有効期限として記録する。 4. 入力された名前で、自分をこのグループの最初のメンバーとして登録する（名前表示設定は初期値ON）。 |

## F2. 招待コードでのグループ参加

| 項目 | 内容 |
|---|---|
| 概要 | 既存の家族グループに、招待コードを使って参加する |
| 入力 | 招待コード（6桁）、自分の名前（表示名） |
| 出力 | 参加したグループの情報、自分のメンバーID |
| 処理内容 | 1. 招待コードが存在し、有効期限内かを確認する。 2. 期限切れ、または存在しないコードの場合はエラーを返す（「コードが見つかりません」）。 3. 該当グループのメンバーとして、入力された名前で登録する（名前表示設定は初期値ON）。 4. 1ユーザーが参加できるグループは1つのみのため、既に別グループに参加済みの端末からの参加はエラーとする。 |

## F3. 自宅位置・判定範囲の登録

| 項目 | 内容 |
|---|---|
| 概要 | 自宅の位置（緯度・経度）と、「在宅」「施設内」それぞれと判定する範囲（半径）を登録する |
| 入力 | 緯度、経度（現在地取得、または地図上での指定）、在宅判定の半径（50m〜300m、初期値100m）、施設内判定の半径（100m〜2000m、初期値300m、在宅判定の半径以上の値） |
| 出力 | 登録結果 |
| 処理内容 | 1. 端末の位置情報取得機能（OS機能）で緯度・経度を取得する。 2. 2つの半径とあわせて、自分のメンバー情報に保存する。施設内判定の半径は在宅判定の半径以上でなければならない（それより狭い値はエラー）。 3. 保存後、アプリ側でこの位置情報・2つの半径をもとに、OSへ2重のジオフェンス監視を登録する（F4）。 |

## F4. 在宅／施設内／外出の自動判定

| 項目 | 内容 |
|---|---|
| 概要 | 自宅の範囲・その一回り外側の範囲への出入りを検知し、「在宅」「施設内」「外出中」の3段階のステータスを自動更新する |
| 入力 | OSからのジオフェンス出入り通知（アプリ非起動時も含む） |
| 出力 | 更新後のステータス（home/nearby/away）、更新時刻 |
| 処理内容 | 1. F3で登録した位置・2つの半径をもとに、OSの位置情報機能へ2重のジオフェンス監視を登録する。 2. いずれかの境界をまたいだイベントが発生するたびに、その時点の現在地から自宅までの距離を計算し直し、在宅判定の半径以内なら「home」、それを超え施設内判定の半径以内なら「nearby」、それも超えていれば「away」と判定する（単一のイベントだけに頼らず、都度3段階を再計算する）。 3. 直前と判定結果が変わらない場合は、通信・通知を発生させない。 4. 変化した場合はサーバーへ状態とタイムスタンプを送信する。サーバーは受け取った内容でスプレッドシートのメンバー情報を更新し、在宅中の詳細な状態（F16）は自動的に空へ戻す。 5. 状態が変化した場合、同じグループの他メンバーへ通知要否を判定する（F9）。 |

## F5. ホーム画面（家族一覧）表示

| 項目 | 内容 |
|---|---|
| 概要 | 同じグループのメンバー全員の状態を一覧表示する |
| 入力 | グループID |
| 出力 | メンバーごとの「表示名（または匿名）」「ステータス（在宅／施設内＝呼び方／外出中）」「最終更新時刻」「在宅中のみ：詳細な状態」「管理者バッジ」、在宅人数 |
| 処理内容 | 1. サーバーへグループ内メンバーの最新状態を問い合わせる。 2. 各メンバーの「名前を家族に表示する」設定がOFFの場合は、名前を伏せて「メンバー」等の匿名表示にする（本人の行は常に本人の名前を表示）。 3. 在宅人数（在宅人数／総人数。「施設内」は在宅人数に含めない）を集計して表示する。 4. ステータスが「施設内」のメンバーは、固定文言ではなくグループ共通の「呼び方」（F13）を表示する。 5. ステータスが「在宅」かつ詳細な状態（F16）が設定されているメンバーは、それを小さく添えて表示する。 6. グループの管理者（F12）には管理者バッジを表示する。 7. 画面右上の「更新」ボタンで、いつでも手動で最新の状態を再取得できる。 |

## F6. 手動でのステータス切り替え

| 項目 | 内容 |
|---|---|
| 概要 | 自動判定を待たず、自分から「在宅」「施設内」「外出中」のいずれかへ切り替え、家族へ知らせる |
| 入力 | 3択の切替操作（ボタン押下） |
| 出力 | 切替結果、家族への通知（「施設内」への切替時を含む） |
| 処理内容 | 1. 自分のステータスを選択した値に更新する（F4の自動判定と同じ経路で更新）。 2. 同じグループの他メンバーへ、通知設定がONの端末に対してのみプッシュ通知を送信する（本文は「〜が帰宅しました」「〜が（呼び方）に移動しました」「〜が外出しました」）。 3. 切替に伴い、在宅中の詳細な状態（F16）は自動的に空へ戻る。 |

## F7. プロフィール・表示設定

| 項目 | 内容 |
|---|---|
| 概要 | 自分の名前の変更、および名前を家族に表示するかどうかの設定 |
| 入力 | 変更後の名前、名前表示設定（ON/OFF） |
| 出力 | 更新結果 |
| 処理内容 | 1. 入力内容でメンバー情報を更新する。 2. 表示設定は自分のみが変更でき、即座にホーム画面（F5）の表示へ反映される。 3. 「施設内」の呼び方は個人設定ではなくグループ共通の設定（F13）に分離されているため、本機能では扱わない。 |

## F8. 自宅設定の変更

| 項目 | 内容 |
|---|---|
| 概要 | 設定画面から、登録済みの自宅位置・判定範囲（在宅／施設内の両方）を変更する |
| 入力 | F3と同じ |
| 出力 | F3と同じ |
| 処理内容 | F3の登録内容を上書きする。変更後、ジオフェンス監視も新しい設定で登録し直す。 |

## F9. 通知設定

| 項目 | 内容 |
|---|---|
| 概要 | 家族の状態変化（在宅／施設内／外出）をプッシュ通知で知らせる機能のON/OFF |
| 入力 | 通知設定（ON/OFF） |
| 出力 | 更新結果 |
| 処理内容 | 1. 自動判定（F4）・手動切替（F6）のいずれについても、通知設定がOFFの端末へはプッシュ通知を送信しない。 2. 設定はメンバーごとに個別に保持する（自分が受け取るかどうかの設定であり、他人の通知有無には影響しない）。 3. 通知の送信経路は、ネイティブアプリを利用中の端末にはExpo Push、Web版（F14）を利用中の端末にはWeb Push（F15）を用いる。片方の送信に失敗しても、もう一方の送信や状態更新自体には影響しない。 |

## F10. 招待コードの確認・コピー

| 項目 | 内容 |
|---|---|
| 概要 | 設定画面で、自グループの招待コードを確認・コピーできる |
| 入力 | なし（表示のみ） |
| 出力 | 招待コード、有効期限 |
| 処理内容 | 招待コードが期限切れの場合は、その旨を表示し、再発行操作を提供する（再発行すると新しい7日間の有効期限のコードが発行され、古いコードは無効になる）。 |

## F11. グループからの退出

| 項目 | 内容 |
|---|---|
| 概要 | 参加している家族グループから抜ける |
| 入力 | 退出操作（確認ダイアログでの最終確認を含む） |
| 出力 | 退出結果、スタート画面への遷移 |
| 処理内容 | 1. 自分のメンバー情報をグループから削除する（他メンバーの一覧から見えなくなる）。 2. 端末内に保存していたグループ情報・自宅設定をクリアし、スタート画面に戻す。 3. グループの最後の1人が退出した場合、グループ自体を削除する。 |

## F12. 管理者による代理でのステータス変更

| 項目 | 内容 |
|---|---|
| 概要 | グループの管理者が、他のメンバーのステータスを代わりに手動で変更できる |
| 権限 | グループを作成した人が自動的に管理者になる（1グループに1人。後から移譲する機能はない）。既存のグループ（管理者機能追加前に作成されたもの）では、作成日時が最も古いメンバーを暫定的に管理者とみなす |
| 入力 | 対象メンバーの選択（アプリ版：名前を長押し／Web版：名前をタップ）、変更後のステータス（3択） |
| 出力 | 変更結果、対象メンバー・家族への通知（F6と同じ） |
| 処理内容 | 1. 操作者が対象メンバーと同じグループの管理者であることをサーバー側で確認する（管理者以外や本人以外からの操作は拒否）。 2. 確認後はF6と同じ経路でステータスを更新する。 |

## F13. 呼び方（「施設内」ステータスの表示名）の設定

| 項目 | 内容 |
|---|---|
| 概要 | 「施設内」ステータスの表示名（初期値「施設内」、例：「ロビー」）を、グループ共通の1つの値として設定する |
| 権限 | 管理者のみ変更できる。管理者以外の設定画面には、現在の値が読み取り専用で表示される |
| 入力 | 呼び方の文字列（1〜12文字） |
| 出力 | 更新結果。以後、グループ全員のホーム画面・通知文言に反映される |
| 処理内容 | 1. グループ情報（呼び方）を更新する。 2. 更新後は、全メンバーの一覧表示・手動切替ボタンのラベル・通知文言のすべてに同じ値が使われる。 |

## F14. Web版（ブラウザ簡易画面）

| 項目 | 内容 |
|---|---|
| 概要 | ネイティブアプリを入れられない端末（主にiPhone）向けに、招待コード参加・一覧表示・手動でのステータス切替・各種設定をブラウザだけで行える簡易画面を提供する |
| 対応機能 | グループ参加（F2）、一覧表示（F5）、手動でのステータス切替（F6、3択）、管理者による代理変更（F12）、呼び方の設定（F13）、名前・表示設定（F7）、在宅中の詳細な状態（F16）、通知設定（F9、Web Push）、招待コードでの参加のみ（グループ作成はネイティブアプリのみ）、グループからの退出（F11） |
| 制約 | バックグラウンドでの位置情報監視ができないため、自動判定（F4）は行わない。画面を開いたまま自動更新されるのは、通知を受信した瞬間（Service Workerからの合図）と、画面が再び表示状態になった瞬間（アプリ切替・ホーム画面からの再起動時）のみで、それ以外は「更新」ボタンでの手動更新、またはページの再読み込みが必要 |
| 処理内容 | ネイティブアプリと同じAPIサーバーのエンドポイントを、端末ごとに発行した`device_id`（ブラウザのlocalStorageに保存）を使って呼び出す。ログイン機能は持たない点もネイティブアプリと同様 |

## F15. Web版のプッシュ通知（Web Push）

| 項目 | 内容 |
|---|---|
| 概要 | Web版でも、家族の状態変化をプッシュ通知で受け取れるようにする |
| 入力 | 通知の許可操作（ブラウザの許可ダイアログ） |
| 出力 | 購読情報の登録、以後の通知受信 |
| 処理内容 | 1. Service Worker（`sw.js`）を登録し、ブラウザ標準のPush APIで購読情報（endpoint・鍵）を作成する。 2. 購読情報をサーバーに登録する。 3. 状態変化時、サーバーはこの購読情報宛にWeb Push（VAPID）で通知を送る。 4. 通知受信時、Service Workerは通知の表示と同時に、開いている画面へ「一覧を更新して」という合図を送る（F5の即時更新）。 |
| 重要な制約 | **iPhoneのSafariでは、ページを普通のタブで開いているだけでは通知を受信できない**。一度「ホーム画面に追加」し、そのアイコンから開いた場合のみ有効になる（iOS 16.4以降が必要）。この条件を満たさない場合は、その旨を画面に案内する。 |

## F16. 在宅中の詳細な状態

| 項目 | 内容 |
|---|---|
| 概要 | ステータスが「在宅」の間、「トイレ中」「入浴中」など任意の一言メモを添えられる |
| 権限 | 本人のみ設定できる（管理者による代理設定は不可） |
| 入力 | 自由入力の文字列（0〜12文字、空文字は未設定に戻すことを意味する） |
| 出力 | 更新結果。ホーム画面の一覧に、対象メンバーの行へ小さく表示される |
| 処理内容 | 1. 入力欄からの離脱・キーボードの確定操作・「更新」ボタン・「×」ボタン（即クリア）のいずれかで保存する。 2. ステータスが「在宅」以外に変わったとき（F4・F6・F12のいずれの経路でも）、この値は自動的に空へ戻す（次に在宅になったときに前回の内容が残らないようにするため）。 3. 在宅人数のカウント（F5）には影響しない。 |

## F17. 一覧の手動更新

| 項目 | 内容 |
|---|---|
| 概要 | ホーム画面の右上（Web版も同様）にある「更新」ボタンで、家族全員の最新の状態をいつでも手動で取得し直せる |
| 入力 | 更新操作（ボタン押下） |
| 出力 | 最新化された一覧 |
| 処理内容 | サーバーへメンバー一覧を再取得し、画面を再描画する（アプリ版は既存の定期更新・pull-to-refreshに加えたショートカット、Web版は自動更新が限定的なための主な更新手段）。 |
