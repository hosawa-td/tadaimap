# タダイマップ（APIサーバー）

Node.js / Express製のAPIサーバー。Googleスプレッドシートを簡易データベースとして利用する。

## セットアップ

```bash
npm ci
cp .env.example .env
# .env にスプレッドシートID・サービスアカウントの情報を貼り付ける
npm run dev
```

`.env` を設定しない場合は、インメモリの簡易データで起動します（開発時の一時的な動作確認用）。

## テスト

```bash
npm test
```

インメモリのリポジトリを使い、API設計書のすべてのエンドポイント（正常系・主要な異常系）を検証します。
